# 方塊突擊 Block Strike

方塊人風格的網頁版 5 對 5 爆破模式射擊遊戲，單機對電腦。Three.js 寫成，不用安裝、不用建置。

## 怎麼玩

需要用本機伺服器開（直接點兩下 `index.html` 會被瀏覽器擋掉模組載入）：

```bash
cd block-strike && python3 -m http.server 8000
```

然後用電腦瀏覽器開 `http://localhost:8000`。需要鍵盤滑鼠，手機不支援。

| 按鍵 | 動作 |
|---|---|
| W A S D | 移動 |
| 空白 / C / Shift | 跳 / 蹲 / 靜步 |
| 滑鼠左鍵 / 右鍵 | 射擊 / 狙擊槍開鏡 |
| R | 換彈 |
| 1 / 2 / 3 / Q | 主武器 / 手槍 / 小刀 / 上一把 |
| B | 購買（回合開始 20 秒內，開啟後按數字鍵） |
| 按住 E | 安裝／拆除炸彈 |

## 規則

- 進攻方到 A 或 B 點安裝炸彈（3 秒），38 秒後引爆；防守方要拆除（5 秒）或守到時間結束
- 任一方全滅也算分出勝負；先拿 7 回合的一方獲勝
- 擊殺 +$300、安裝 +$300、回合勝 +$3000、敗 +$1800；陣亡會失去主武器與護甲

## 地圖

三張都是原創配置，定義在 `maps.js`（先填滿牆、再挖出通道、最後擺箱子）：

- **沙城**：三路進攻的沙漠小鎮，左側有隧道
- **綠洲市集**：對稱的中央廣場
- **貨運站**：貨櫃場，小而快的近戰圖

## 檔案

- `index.html`：選單與 HUD
- `game.js`：繪圖、移動與碰撞、射擊、機器人（A* 尋路）、回合流程、合成音效
- `maps.js`：地圖定義
- `vendor/`：Three.js r170（MIT 授權）

網址加上 `?test` 會略過滑鼠鎖定，並開放 `window.__g` 供自動測試步進模擬。
