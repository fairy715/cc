# token-meter

Claude Code mod：每次送出訊息、Claude 回覆完之後，顯示該次的 token 用量與費用（美元＋台幣）。

## 會看到什麼

- **輸入框上方一行**（彩色）：`◆ 上次 1.0K 入（快取 90%）· 50 出 · NT$8.00 US$0.2500 ｜ 累計 NT$56.00  /tokens 看明細`
- **狀態列**：`本次 US$0.2500（NT$8.00） ｜ 累計 US$1.7500（NT$56.00）`
- **`/tokens` 指令**：Markdown 報表，包含累計、平均、最貴一次，以及最近 10 次的表格（輸入、快取命中率、輸出、費用長條圖、美元、台幣、耗時）

```
### 💰 本 session 累計 US$4.1729 · NT$133.11
共 3 次送出 · 平均每次 US$0.4685（NT$14.94） · 最貴第 1 次 NT$35.40

| # | 輸入  | 快取命中 | 輸出  | 費用       | USD     | 台幣     | 耗時 |
|  1| 2.76M |      99% | 14.7K | ██████████ | $1.1097 | NT$35.40 | 155s |
|  2| 1.05M |     100% |  1.0K | ██░░░░░░░░ | $0.2440 |  NT$7.78 |  30s |
|  3| 176.2K|     100% |   804 | ░░░░░░░░░░ | $0.0517 |  NT$1.65 |  12s |
```

## 計算方式

- token：把該次送出期間每個 API 回應的用量加總（主對話＋子代理）。「輸入」= 未快取輸入＋快取讀取＋快取寫入。
- 費用：取 Claude Code 自己的費用帳本（與 `/cost`、狀態列同一個數字），算送出前後的差額，所以子代理、快取都已含在內。
- 訂閱制（Pro/Max）下這是「等值 API 價格」，不是實際扣款。

## 台幣匯率

- 預設每次 session 開始時從 `open.er-api.com` 抓 USD/TWD 即時匯率（`/tokens` 會標示「即時」）。
- 抓不到（離線、公司網路擋掉）或關閉即時匯率時，使用設定值，預設 31.9（標示「設定值」）。
- 在 `/config` 的 plugin 設定可以調整：
  - `twdRate`：備用匯率（1 USD 兌多少 TWD）
  - `liveRate`：是否抓即時匯率

## 安裝

```
/plugin install token-meter --marketplace fairy715/cc
```

出現 `Add marketplace?` 時按 `y`，再選安裝範圍（user）。
